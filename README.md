# Health Classification Model
A machine learning project that predicts a patient's health condition from clinical measurements.

## Goal
Learn to build a multi-class classification model that predicts health conditions from patient data.

## Dataset
**Name:** "Student Health Risk Prediction Dataset"
**Source:** Kaggle, https://www.kaggle.com/datasets/jendoubiahmed/playground-series-s6e7
**Owner:** Ahmed Jenddoubi, Ph.D.
**Dataset Files:** train.csv, test.csv

## Models
Random Forest
Logistic Regression
Decision Tree
